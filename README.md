### Giới thiệu

Chào bạn, mình là **Gia Bảo**. Đây là trang GitHub cá nhân nơi mình lưu trữ mã nguồn các bài thực hành, bài tập lớn và dự án môn học trong quá trình theo học ngành **Thiết kế Vi mạch** tại Đại học FPT.

---

### Kiến thức & Công cụ đang học

- **Ngôn ngữ:** `Verilog HDL`, `C / C++`, `Python` cơ bản, `Bash script`.
- **Thiết kế số & Mô phỏng:** Viết code Verilog cho các khối logic cơ bản (FSM, Datapath, bộ đếm, bộ cộng/trừ), viết testbench mô phỏng kiểm tra chức năng bằng `ModelSim` và `Vivado`.
- **Hệ thống nhúng & Phần cứng:** Lập trình C cơ bản trên Linux nhúng (tìm hiểu character driver đơn giản), lập trình vi điều khiển `ESP32`, tập vẽ mạch nguyên lý và layout PCB 2 lớp bằng `KiCad`.
- **Môi trường & Công cụ:** `Linux (Ubuntu)`, `Git`.

### Một số bài tập lớn & Dự án môn học

- **[image-dsp-benchmark](https://github.com/ntue2719-commits/image-dsp-benchmark)** *(Làm cùng bạn [@ntue2719-commits](https://github.com/ntue2719-commits))*:
  Mô phỏng thuật toán lọc ảnh 2D cơ bản bằng Verilog trên FPGA.

- **[secDED-bpsk-fpga](https://github.com/ntue2719-commits/secDED-bpsk-fpga)** *(Làm cùng bạn [@ntue2719-commits](https://github.com/ntue2719-commits))*:
  Bài tập lớn môn học: hiện thực khối Datapath và testbench kiểm tra mã sửa lỗi Hamming (SEC-DED) kết hợp điều chế BPSK.

- **[LOS (Embedded Linux Systems)](https://github.com/weliuliu123-byte/LOS)**:
  Kho bài tập thực hành môn Hệ thống Linux nhúng (LOS201): làm quen quy trình build kernel, chạy giả lập QEMU ARM và viết driver character device cơ bản.

- **Mạch giám sát nhiệt độ (ESP32)**:
  Mạch đo nhiệt độ dùng vi điều khiển ESP32, vẽ bo mạch PCB bằng KiCad và thử nghiệm thuật toán điều khiển quạt PID.
